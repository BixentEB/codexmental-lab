Personnaliser le Web à sa manière

PlateformeNavigateur Web
StatutEn réflexion
ÉtatConcept en réflexion · nom provisoire

Fonctionnalités

  • Styles CSS personnalisés par site
  • Scripts JavaScript indépendants
  • Activation et désactivation rapides
  • Bibliothèque de profils et de thèmes
  • Importation, exportation et sauvegarde

Concept

Un gestionnaire de styles CSS et de scripts JavaScript pour modifier l'apparence et certains comportements des sites web, sans toucher à leur code d'origine.
