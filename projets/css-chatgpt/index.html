Repeindre les sites qu'on utilise tous les jours

Changer l'apparence des sites web à sa façon (couleurs, fonds, animations, petits ajouts pratiques) grâce à des feuilles de style CSS et de petits scripts, sans toucher au site d'origine.

Aujourd'hui, ça passe par deux extensions gratuites, Stylus pour les styles et Tampermonkey pour les scripts. Le premier thème complet, « Blue Stellar », habille ChatGPT : c'est l'exemple de cette page, avec ses codes prêts à installer. L'étape suivante sera une extension maison qui rassemblera tout ça en un seul outil.

Fonctionnalités

  • Couleurs — repeindre un site entier, du fond aux boutons
  • Fonds et animations — champ d'étoiles, étoiles filantes, lueurs au survol
  • Rangement — réorganiser l'affichage (projets en capsules…)
  • Petits ajouts — un script qui ajoute une info utile, comme le titre de la conversation
  • Réversible — un clic sur l'extension et le site redevient normal

Fonctionne déjà

  • Styles CSS appliqués avec Stylus
  • Petits scripts avec Tampermonkey
  • Thème « Blue Stellar » pour ChatGPT, installable en un clic

En cours

  • Ajustements du thème au fil des changements de ChatGPT
  • Script du titre de conversation

Envisagé

  • Une extension maison, sans passer par Stylus ni Tampermonkey
  • Profils de thèmes et activation site par site
  • D'autres sites habillés, sur le même principe

Comment ça marche

Une feuille de style CSS dit au navigateur comment dessiner une page : couleurs, fonds, bordures, animations. Une extension comme Stylus en ajoute une par-dessus celle du site, uniquement chez vous. Pour aller plus loin qu'une simple couleur (ajouter une information, réagir à ce qui se passe à l'écran), un petit script JavaScript prend le relais avec Tampermonkey.

Prochaines étapes

Extension maison : gestion de profils CSS/JS, activation indépendante selon les sites
